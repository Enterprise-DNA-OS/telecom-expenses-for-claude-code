# Add a report

Read CLAUDE.md, views.json and the database views. Translate the operator's question to a read-only query. Keep currency groups separate, show the source record codes and avoid counting charges twice through one-to-many joins. Add a named section to views.json, run npm run view and open the result. Test it against known records. Keep private reports out of git. Do not add a server, editing control or external data connection.
